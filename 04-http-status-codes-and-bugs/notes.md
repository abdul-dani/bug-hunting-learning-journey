Bug Hunting Notes: HTTP Status Codes and Bugs

What I Learned

- 1xx: Informational
- 2xx: Success
- 3xx: Redirection
- 4xx: Client errors
- 5xx: Server errors

I also learned what a bug means in bug bounty and the difference between client-side bugs, which affect the browser or user interface, and server-side bugs, which affect server-side processing or logic.

Key takeaway: Understanding how web applications behave helps me identify and investigate potential security issues.
